# BUG-001 — Ошибка импорта модуля validation

**Статус:** Исправлено

**Тип:** Ошибка тестового окружения

**Тяжесть:** Низкая (Low)

**Приоритет:** Средний (Medium)

## Описание

При запуске модульных тестов возникала ошибка
ModuleNotFoundError: No module named 'validation'.

Python не мог найти модуль validation при сборе тестов.

## Шаги воспроизведения

1. Открыть проект в Visual Studio Code.
2. Открыть терминал.
3. Запустить команду pytest -v.
4. Проверить вывод терминала.

## Ожидаемое поведение

Тестовые модули должны импортироваться,
а pytest должен начать выполнение тестов.

## Фактическое поведение

При сборе тестов возникала ошибка
ModuleNotFoundError.

## Исправление

Для запуска тестов использована команда:

python -m pytest -v

После изменения способа запуска тесты
выполняются успешно.

## Результат

Проблема устранена. Повторный запуск
показал успешное выполнение тестов.
