# Документация тестирования системы шифрования

## 1. Общие сведения

Название проекта: Система шифрования.

Вариант: 8.

Язык программирования: Python.

Инструмент тестирования: pytest.

Дополнительный инструмент: pytest-cov.

Метод тестирования: комбинаторное покрытие условий.

## 2. Цель тестирования

Проверка правильности работы системы шифрования,
корректности обработки входных данных и взаимодействия
программных модулей.

## 3. План тестирования

1. Проверка модуля cipher.py.
2. Проверка модуля validation.py.
3. Проверка покрытия решений.
4. Проверка покрытия условий.
5. Проверка комбинаций условий.
6. Интеграционное тестирование.
7. Анализ покрытия кода.
8. Инспекция программного кода.

## 4. Тестовые сценарии

### Сценарий 1. Шифрование

Входные данные: ABC, ключ 3.

Ожидаемый результат: DEF.

### Сценарий 2. Расшифрование

Входные данные: DEF, ключ 3.

Ожидаемый результат: ABC.

### Сценарий 3. Проверка некорректного текста

Входные данные: пустая строка.

Ожидаемый результат: ValueError.

### Сценарий 4. Проверка неправильного ключа

Входные данные: ключ 0.

Ожидаемый результат: ValueError.

### Сценарий 5. Интеграционное тестирование

Проверка полного цикла шифрования и расшифрования.

Ожидаемый результат: восстановление исходного текста.

## 5. Результаты тестирования

Инструмент: pytest.

Количество тестов: 37.

Количество успешно пройденных тестов: 37.

Количество ошибок: 0.

## 6. Метрики покрытия

Покрытие модуля cipher.py: 100%.

Покрытие модуля validation.py: 100%.

Общее покрытие: указать 100%.

Требуемое покрытие: не менее 75%.

## 7. Вывод

В ходе тестирования проверена работа модулей системы
шифрования, корректность входных данных и взаимодействие
между программными компонентами.

Результаты тестирования зафиксированы с помощью pytest
и pytest-cov.
